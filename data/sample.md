# Retrieval-Augmented Generation

## What is RAG?

RAG stands for Retrieval-Augmented Generation.

A RAG system retrieves relevant information from a knowledge
source and provides that information as context to a language model.

## Why RAG is Useful

RAG can help a language model answer questions using information
from a specific knowledge base.
